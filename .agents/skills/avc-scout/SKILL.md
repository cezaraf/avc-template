# Scout the next signal

Follow `.avc/roles/scout.md`. Require the active run id, revision, tree/HEAD,
question, and stop condition. Search targeted symbols and files first. Query
ai-memory for prior decisions or gotchas when they may change the next decision,
then verify them in the current tree.

Run the cheapest safe command that establishes the baseline. Separate observed
facts, configuration, general capability, hypotheses, and unproved behavior.
Identify confirmed risk impacts separately from keyword/path signals. Recommend
only the next one to three observable nodes and their minimal paths.

Do not edit. Return every key from `.avc/templates/agent-result.yaml` with exact
argv and exit code. Stop when the requested baseline and surface are factual.
