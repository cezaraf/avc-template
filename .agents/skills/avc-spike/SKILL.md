# Run a bounded spike

Follow the Scout authority unless a separate disposable write surface is
explicitly authorized. Define one question, prediction, time budget, permitted
paths, command/environment, and stop condition. Search ai-memory for prior
attempts and gotchas, then verify current applicability.

Prefer a benchmark, reproduction, throwaway prototype, or targeted read. Mark
all spike code disposable; it does not become production without a new
authorized implementation node and oracle. Stop at the configured timebox or
when the decision is supported.

Return the canonical result with evidence, limitations, and one recommended
next decision. More speculative planning is not a successful spike.
